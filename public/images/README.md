# DEAR DAD - CUSTOM IMAGE PATHS

Drop your custom photos into this directory using the filenames below.
The layout is styled with aspect-ratio containers and a subtle grain filter, so it will look clean until you add your real photos.

### Image Mapping Guide:

1. **Hero Portrait (Full Viewport background)**
   - Path: `public/images/hero-dad.jpg`
   - Aspect Ratio: Portrait (e.g. 3:4 or 9:16), high resolution cover.

2. **Memories Section (Alternating grid)**

   - `public/images/memory-3.jpg` (family trip - landscape/square)
   - `public/images/memory-4.jpg` (quiet moments - landscape/square)
   - `public/images/memory-5.jpg` (graduation/recent photo - landscape/square)

3. **Timeline Milestones (GSAP horizontal scroll)**

   - `public/images/timeline-school.jpg` (first day of school - landscape/square)
